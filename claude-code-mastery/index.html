একা কামার — The Lone Blacksmith

পুরান ঢাকার এক গলিতে দুটো কামারশালা ছিল। প্রথমটার মালিক মিন্টু কামার — সব কাজ নিজের হাতে: লোহা নিজে গরম করা, নিজে ঘষা, নিজে জোড়া। লোকে বলত — আসল কারিগর। কিন্তু অর্ডার যত বাড়ল, রাত তত জাগতে হলো; এক সময় কাঁপা হাতে কাজ করতে করতে ভুল হলো, খরিদ্দার ফিরে গেল। পাশের কারখানায় দশ শাগরেদ — একজন শুধু কাটে, একজন শুধু জোড়া দেয়, একজন শুধু পরীক্ষা করে; মালিক শুধু নকশা দেয়, আর শেষ সইটা করে। প্রথমজন কারিগর ছিল। দ্বিতীয়জন মালিক।

Two smithies stood in one lane of Old Dhaka. The first belonged to Mintu the blacksmith — everything by his own hand: heating, grinding, joining. People said — a true craftsman. But as orders grew, nights grew sleepless; one day, working with trembling hands, he erred, and customers left. The smithy next door had ten apprentices — one only cuts, one only joins, one only inspects; the owner only designs, and signs at the end. The first was a craftsman. The second was an owner.

Claude Code শেখার মানে প্রথমটা থেকে দ্বিতীয়টা হওয়া। টুল চালানো জানা যথেষ্ট নয় — কারখানা চালানো শিখতে হয়: কাকে কোন কাজ দিতে হয়, কোথায় তালা লাগাতে হয়, কখন ঘণ্টা বাজে, আর কী লিখে রাখলে প্রতিটা নতুন সেশন ঠিক কাজ শুরু করে। এই বইয়ের দশটি দরজা সেই কারখানা বানানোর নকশা — প্রতিটি দরজায় একজন উস্তাদ, একটা ধারণা, একটা সিক্রেট।

Learning Claude Code means moving from the first to the second. Knowing the tool is not enough — you must learn to run the workshop: who gets which task, where the locks go, when the bell rings, and what to write down so every new session starts the right work. The ten doors of this book are that workshop's blueprint — each door: one master, one idea, one secret.
