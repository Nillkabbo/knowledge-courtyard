The Terminal Craftsman · Claude Code Mastery
হাতুড়ি থেকে স্থপতি — Claude Code-এর মাস্টারি ষাটটি দরজায়।
ইনস্টল ও প্রথম সেশন, CLAUDE.md স্মৃতি, মডেল পরিবার (Sonnet · Opus · Haiku · Fable), এজেন্ট লুপ ও কনটেক্সটের নদী, পারমিশনের তালা, সাব-এজেন্ট শাগরেদ, হুকের ঘণ্টা, MCP-Skills-Plugins বাজার, রাতের কারখানা (headless · CI · Agent SDK) — মালিকের সিংহাসন শেষ নয় — তারপর উঁচু তলা: সেটিংস-মহাফেজখানা, স্মৃতি-স্থাপত্য, কাস্টম সাব-এজেন্ট, হুক-ইঞ্জিনিয়ারিং, ইঞ্জিন-ঘরের নিয়ন্ত্রণ — শেষে চার দরজার আইডিয়া→প্রোডাক্ট এক্সপার্ট-ওয়ার্কফ্লো: প্রথম দিন, নকশা-টেবিল, কারখানা-ছন্দ, নদী-পারাপার (v1.0.0-রিলিজ)।

From hammer to architect — mastery of Claude Code in thirty-five doors: the craft (first session, CLAUDE.md memory, models, context, permissions, subagents, hooks, MCP + Skills + Plugins, CI, SDK), the customization floor (settings, memory architecture, custom agents, hook engineering, the engine room) — then a four-door expert workflow that carries an idea to a shipped v1.0.0, ending at the Architect's Throne. Every command grounded in the official Claude Code documentation.
একা কামার — The Lone Blacksmith

পুরান ঢাকার এক গলিতে দুটো কামারশালা ছিল। প্রথমটার মালিক মিন্টু কামার — সব কাজ নিজের হাতে: লোহা নিজে গরম করা, নিজে ঘষা, নিজে জোড়া। লোকে বলত — আসল কারিগর। কিন্তু অর্ডার যত বাড়ল, রাত তত জাগতে হলো; এক সময় কাঁপা হাতে কাজ করতে করতে ভুল হলো, খরিদ্দার ফিরে গেল। পাশের কারখানায় দশ শাগরেদ — একজন শুধু কাটে, একজন শুধু জোড়া দেয়, একজন শুধু পরীক্ষা করে; মালিক শুধু নকশা দেয়, আর শেষ সইটা করে। প্রথমজন কারিগর ছিল। দ্বিতীয়জন মালিক।

Two smithies stood in one lane of Old Dhaka. The first belonged to Mintu the blacksmith — everything by his own hand: heating, grinding, joining. People said — a true craftsman. But as orders grew, nights grew sleepless; one day, working with trembling hands, he erred, and customers left. The smithy next door had ten apprentices — one only cuts, one only joins, one only inspects; the owner only designs, and signs at the end. The first was a craftsman. The second was an owner.

Claude Code শেখার মানে প্রথমটা থেকে দ্বিতীয়টা হওয়া। টুল চালানো জানা যথেষ্ট নয় — কারখানা চালানো শিখতে হয়: কাকে কোন কাজ দিতে হয়, কোথায় তালা লাগাতে হয়, কখন ঘণ্টা বাজে, আর কী লিখে রাখলে প্রতিটা নতুন সেশন ঠিক কাজ শুরু করে। এই বইয়ের ষাটটি দরজা সেই যাত্রার নকশা — প্রতিটি দরজায় একজন উস্তাদ, একটা ধারণা, একটা সিক্রেট।

Learning Claude Code means moving from the first to the second. Knowing the tool is not enough — you must learn to run the workshop: who gets which task, where the locks go, when the bell rings, and what to write down so every new session starts the right work. The thirty-five doors of this book are that journey's blueprint — each door: one master, one idea, one secret.

ষাটটি দরজা পেরিয়েছ।

হাসু মিস্ত্রির প্রথম হাতুড়ি, রাহেলা খাতুনের নোটবই, তিন ভাই ও দাদার মাপকাঠি, ফরিদার নদীর বোঝা, বেলালের তালা, রফিকের ঠিকাদারি, মাহমুদের ঘণ্টা, আয়েশার আংটি, নাদিরের রাতের কারখানা — দশটি স্তর এক কারখানা; তারপর সিরাজের ঘড়ির ভেতরের ইঞ্জিন, নুসরাতের নিজের লেখা, কামরুলের নিজে গড়া যন্ত্র, মোস্তফার পাইকারি বাক্স, রাহাতের স্থাপত্য; তারপর ফটিক চাচার প্রথম দিন, রূপালী পাশার নকশা-টেবিল, শামসু ভূইয়ার কারখানা-ছন্দ, আনোয়ার পাঠানের নদী-পারাপার — এখন আইডিয়া থেকে প্রোডাক্ট, পুরো যাত্রাটাই তোমার হাতে।

এই সংস্করণে মুনশি আবদুল করিমের ঘড়ির-কাঁটা, হরফের-খোপের মুসাব্বির, পাশার পাশা-খেলা, তালিমঘরের তিন-ধাপ, পেশকারের টেবিল, ওয়ার্ড-বয়ের ফাইল, সীসা-পাতের মোহরি, বেয়ারার চিরকুট — ভেতর-ঘরের আট রহস্য; সাথে দালালের ফার্মান, পাশ-কাগজের মনসবোয়াং, কম্পোজারের ছাঁচ, আর নছিমনের বারো-লাইনের ইঞ্জিন — যন্ত্রটা এখন তুমি নিজে বানাতে জানো।

শেষ চার গভীর-দরজায় রাহেলা খাতুনের গূঢ়-খাতা, মরিয়মের তালিমনামা-কারখানা, কামরুল মিয়ার প্যাকেজ-ঘর, ইদ্রিস মাস্টারের উস্তাদ-ঘর — স্মৃতি, পদ্ধতি, বিতরণ, বিভাজন: এখন তুমি কারখানাটাই নকশা করো।

ল্যাব-তলায় তুষারের খাতা-ল্যাব, সাদিয়ার তালিম-ল্যাব, ফারুকের উস্তাদ-ল্যাব, জামালের প্যাকেজ-ল্যাব — আর শেষে নিজের হাতে কারখানা-উদ্বোধন: পড়া শেষ, এখন বানানো।

তুমি আর শুধু কারখানার মালিক নও — তুমি সেই স্থপতি, যে কারখানার যন্ত্রগুলোই বানায়: নিজের হুক, নিজের কমান্ড, নিজের সার্ভার, নিজের প্লাগইন, নিজের ইঞ্জিন।
