### Fix 1 — Reconstruct broken `tools-mcp` (Book 19)

**Root cause (verified):** Doors 3, 4, 5 (in `doors-1-5.js`) and doors 7, 9 (in `doors-6-10.js`) deviate from the standard bilingual pattern used by all other 12 AI books. Instead of one `story:\`...\`` template holding both Bengali and English (English wrapped in `<p class="scene-setting en">` / `<div class="dialogue en">`), these doors have:
- A stray comma `</div>,` terminating the English dialogue at `doors-1-5.js:303, 492, 602` and `doors-6-10.js:137` (plus likely more in doors 8/9/10),
- A **second `story:\`...\`` field** appended to the same door object holding a garbled/duplicated English retelling (e.g. `doors-1-5.js:494-496` is visibly corrupted — a sentence fragment is pasted mid-paragraph).

This makes both files fail `node --check`, so the entire tools-mcp book fails to render.

**Fix approach — reconstruct, don't patch:**
For each malformed door, collapse the two `story:` fields into ONE template literal that follows the exact canonical pattern (confirmed in `ai-agents/doors-1-5.js` and the correct doors 1/2/6/10 of tools-mcp itself):
```
story:`<p class="scene-setting">বাংলা...</p>
<p class="scene-setting en">English...</p>

<div class="dialogue">বাংলা...</div>
<div class="dialogue en">"English..."</div>

<div class="code-block">...ascii tables/diagrams...</div>

<div class="dialogue">বাংলা spirit...</div>
<div class="dialogue en">"English spirit..."</div>`
```
- **Preserve intact:** all `<div class="code-block">` technical content (the MCP JSON-RPC spec, tool patterns, testing categories — this is the valuable, accurate content), all `secret`, `recall`, `senior`, `spirit` fields.
- **Reconstruct cleanly:** the English scene-setting + dialogue from the garbled second-story fields, deduplicating the corruption. Where the English is just a duplicate of Bengali, write a faithful English parallel (the door's `secret`/`senior` already give me the meaning).
- **Verify after each file:** run `node --check tools-mcp/doors-1-5.js` and `node --check tools-mcp/doors-6-10.js` — must pass clean. Then confirm 10 doors total push correctly (`grep -c 'doors.push'`).

**Sanity guardrails:** door count stays 5 + 5 = 10; no `num:` changes; the MCP/Computer-Use/framework technical content is preserved verbatim.

### Fix 3 — Rename `deep-learning` (Book 25) English tag

**Root cause (verified):** Book 25's folder is `deep-learning/` and `index.html:1108` tags it `Book 25 · Deep Learning Science`, but the book contains **zero ML content** — it's a meta-learning / skill-acquisition book (20h/10000h, Dunning-Kruger, feedback loops, Hebb, unlearn/relearn). In 2026 "deep learning" overwhelmingly means neural networks, so this misleads learners. Its Bengali title `গভীর জ্ঞানের সভা` ("Assembly of Deep Knowledge") is fine and unambiguous.

**Fix:** Change only the English tag in `index.html:1108` from `Deep Learning Science` → `The Art of Deep Learning` (keeps "deep learning" as a skill phrase, removes the ML collision). Folder name stays `deep-learning/` (renaming the folder would break the `game-25` class, the href, and all internal links — out of scope). Once Fix 2 lands, the "Book 25 = research-paper" clash is already gone, so no further numbering work is needed here.
