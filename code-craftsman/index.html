Ten programming books distilled into one Python project. Each door makes the same code cleaner — from apprentice to craftsman.
📜 প্রস্তাবনা — কোডের কসবা

তুমি প্রোগ্রাম লিখতে পারো। কিন্তু একটা প্রশ্ন তোমাকে তাড়া করে — আমার কোড কি ভালো? কীভাবে সিনিয়র ইঞ্জিনিয়াররা কোড লেখেন? কেন Google, Stripe, GitHub-এর কোড এত পরিচ্ছন্ন? এই বই সেই উত্তর দেবে।

You can write programs. But one question haunts you — is my code good? How do senior engineers write code? Why is code at Google, Stripe, GitHub so clean? This book answers that.

এখানে তুমি একটা Task Manager বানাবে — Python দিয়ে, শূন্য থেকে। প্রতিটা দরজায় একজন কারিগর আসবেন — একটি বইয়ের জ্ঞান নিয়ে। দরজা ১-এ নাম ঠিক করো (Clean Code)। দরজা ৪-এ ডুপ্লিকেশন দূর করো (Pragmatic Programmer)। দরজা ৮-এ if/else চেইন ভাঙো (Design Patterns)। দরজা ১৩-এ টেস্ট আগে লেখো (TDD)। দরজা ১৭-এ পুরো কোড এক দৃষ্টিতে।

💎 যাত্রার মানচিত্র: ২০টি দরজা, ৪টি ধাপে। ধাপ ১ (দরজা ১-৫): পরিচ্ছন্নতা — নাম, ফাংশন, কমেন্ট, DRY। ধাপ ২ (দরজা ৬-১০): কাঠামো — রিফ্যাক্টর, প্যাটার্ন, ডিফেন্সিভ। ধাপ ৩ (দরজা ১১-১৬): গভীরতা — ডোমেইন, টেস্ট, লেগেসি, অ্যাবস্ট্রাকশন, ঐক্য। ধাপ ৪ (দরজা ১৭-২০): পরিপূর্ণতা — error handling, decorator, higher-order, সম্পূর্ণ কোড।

20 doors across 4 phases. Phase 1 (1-5): Cleanliness. Phase 2 (6-10): Structure. Phase 3 (11-16): Depth. Phase 4 (17-20): Perfection — error handling, decorators, higher-order functions, synthesis.

📖 উৎস গ্রন্থ: Clean Code (Martin, 2008), The Pragmatic Programmer (Hunt & Thomas, 1999/2019), Refactoring (Fowler, 1999/2018), Design Patterns (GoF, 1994), Code Complete (McConnell, 2004), Domain-Driven Design (Evans, 2003), TDD (Beck, 2002), Working Effectively with Legacy Code (Feathers, 2004), SICP (Abelson & Sussman, 1985), The Mythical Man-Month (Brooks, 1975/1995)।
