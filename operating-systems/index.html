যন্ত্রের আত্মা

The Machine's Soul
প্রোগ্রাম থেকে প্রসেস — অপারেটিং সিস্টেমের প্রতিটি স্তর।
দশটি দরজা: প্রসেস ও প্রোগ্রাম, থ্রেড ও কনকারেন্সি, CPU শিডিউলিং, সিঙ্ক্রোনাইজেশন ও মিউটেক্স, ডেডলক, মেমোরি ম্যানেজমেন্ট, ফাইল সিস্টেম, I/O ও ড্রাইভার, কন্টেইনার ও ভার্চুয়াল মেশিন, এবং একটি fork() কলের সম্পূর্ণ যাত্রা।

From program to process — every layer of the operating system. Ten doors: processes and programs, threads and concurrency, CPU scheduling, synchronization and mutexes, deadlocks, memory management, file systems, I/O and drivers, containers and VMs, and one fork() call's complete journey through the kernel.
একটি প্রোগ্রামের জন্ম — The Birth of a Process

তুমি একটি ফাইলে কোড লিখেছো — hello.py। এটি শুধু টেক্সট। ডিস্কে পড়ে আছে। কোনো জীবন নেই। কিন্তু তুমি যখন "python hello.py" চালাও, একটি অদ্ভুত কিছু ঘটে — এই নিষ্প্রাণ টেক্সট জীবন্ত হয়ে ওঠে। মেমোরিতে জায়গা পায়, CPU সময় পায়, একটি পরিচয় (PID) পায়। এটি এখন একটি প্রসেস — জীবন্ত, চলমান, শ্বাসগ্রহণকারী। এই রূপান্তরই অপারেটিং সিস্টেমের কাজ।

You wrote code in a file — hello.py. It's just text. Sitting on disk. No life. But when you run "python hello.py," something magical happens — this lifeless text comes alive. Gets memory, gets CPU time, gets an identity (PID). It's now a process — alive, running, breathing. This transformation is the operating system's job.

এই বই তোমাকে নিয়ে যাবে কম্পিউটারের ভেতরে — সেই লুকানো জগতে যেখানে প্রসেস জন্ম নেয়, মেমোরি ভাগ হয়, CPU সময় বণ্টিত হয়। Dijkstra-এর semaphore, Brinch Hansen-এর monitor, Denning-এর virtual memory — প্রতিটি ধারণা একটি কারিগরের হাত দিয়ে শেখানো হবে। তুমি শুধু সূত্র শিখবে না — তুমি অনুভব করবে কেন একটি OS প্রয়োজন, কীভাবে এটি শত শত প্রসেসকে একসাথে চালায়।

This book takes you inside the computer — the hidden world where processes are born, memory is shared, CPU time is distributed. Dijkstra's semaphore, Brinch Hansen's monitor, Denning's virtual memory — each concept taught through a craftsman's hands. You won't just learn formulas — you'll feel why an OS is needed, how it runs hundreds of processes simultaneously.
