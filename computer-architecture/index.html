The Clockwork Forge
একটা সুইচ থেকে শুরু — কোটি কোটি সুইচের সিম্ফনি।
দশটি দরজা — transistor, logic gates, CPU datapath, pipelining, cache hierarchy, coherence, out-of-order execution, GPU warps, systolic arrays, AI accelerators।

Ten doors: from a single transistor to Google's TPU. How does silicon think? How does hardware shape every line of code you write? Named masters: Shockley, Hennessy, Patterson, Tomasulo, Flynn, Kung — the architects who built the machines that built the future.
সিলিকনের ভেতরে — Inside the Silicon

তুমি প্রতিদিন কোটি কোটি transistor ব্যবহার করো। কিন্তু একটাকেও দেখোনি। তুমি লেখো model.fit() — আর হাজার হাজার matrix multiplication চলে যায় GPU-তে। কিন্তু কীভাবে? একটা transistor থেকে কীভাবে neural network train হয়? একটা AND gate থেকে কীভাবে ChatGPT তৈরি হয়?

You use billions of transistors every day. But you've never seen one. You write model.fit() — and thousands of matrix multiplications flow through a GPU. But how? How does a transistor become a neural network? How does an AND gate become ChatGPT?

এই বই তোমাকে নিয়ে যাবে সিলিকনের ভেতরে। Shockley (১৯৪৭) প্রথম transistor বানিয়েছিলেন — একটা সুইচ, যেটা চালু বা বন্ধ হয়। Hennessy ও Patterson (১৯৮০s) দেখিয়েছিলেন কীভাবে এই সুইচগুলো মিলে একটা CPU তৈরি করে। Tomasulo (১৯৬৭) আবিষ্কার করেছিলেন কীভাবে CPU তোমার কোডের ক্রম পাল্টে দ্রুত চলে। Flynn (১৯৬৬) শ্রেণীবদ্ধ করেছিলেন সমান্তরাল কম্পিউটিংয়ের রূপ। Kung (১৯৮২) তৈরি করেছিলেন systolic array — হৃদপিণ্ডের মতো স্পন্দিত যন্ত্র।

This book takes you inside the silicon. Shockley (1947) built the first transistor — a switch, on or off. Hennessy and Patterson (1980s) showed how these switches become a CPU. Tomasulo (1967) discovered how CPUs reorder your code for speed. Flynn (1966) classified parallel computing. Kung (1982) created the systolic array — a machine that pulses like a heart.
