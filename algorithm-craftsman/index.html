One search engine. Twenty-one doors. Each door adds one algorithm — Big-O to PageRank. Build a real Python search engine, piece by piece, algorithm by algorithm. Not just learn algorithms — build with them.
📜 প্রস্তাবনা — নির্মাণের শপথ

তুমি এই বই খুলেছ কারণ তুমি algorithm জানো — কিন্তু কীভাবে ব্যবহার করবে জানো না। তুমি Big-O পড়েছো, linked list বানিয়েছো, BFS চালিয়েছো। কিন্তু একটা প্রশ্ন তোমাকে তাড়া করে — এগুলো দিয়ে কী বানাই?

You opened this book because you know algorithms — but not how to use them. You studied Big-O, built linked lists, ran BFS. But one question haunts you — what do I build with these?

এই বই সেই উত্তর দেবে। তুমি একটা সম্পূর্ণ সার্চ ইঞ্জিন বানাবে — Python দিয়ে, শূন্য থেকে। প্রতিটা দরজায় একটা করে algorithm যোগ করবে। দরজা ১-এ বাজেট ঠিক করো (Big-O)। দরজা ২-এ ক্রলার বানাও (Recursion)। দরজা ১২-এ হৃদপিণ্ড বসাও (Inverted Index)। দরজা ২০-এ পুরো ইঞ্জিন চালু করো।

এই বই শেষে তোমার হাতে থাকবে একটা কার্যকর search engine — Google-এর মূল ডেটা স্ট্রাকচার তুমি নিজে বানিয়েছ।

🧭 যাত্রার মানচিত্র — The Build Plan: ২১টি দরজা। দরজা ১-৫: ভিত্তি (Big-O থেকে AND query)। দরজা ৬-১০: বুদ্ধি (spell check থেকে Bloom filter)। দরজা ১১-১৫: হৃদপিণ্ড (inverted index থেকে autocomplete)। দরজা ১৬-১৯: স্কেল (PageRank থেকে MapReduce)। দরজা ২০: সম্পূর্ণ ইঞ্জিন। দরজা ২১: আরও পাঁচটা project।

21 doors. Doors 1-5: foundation (Big-O to AND query). Doors 6-10: intelligence (spell check to Bloom filter). Doors 11-15: the heart (inverted index to autocomplete). Doors 16-19: scale (PageRank to MapReduce). Door 20: the complete engine. Door 21: five more projects.

📖 পূর্বশর্ত: Book ২ (DSA Bazaar) পড়া প্রয়োজন — সেখানে প্রতিটা algorithm আলাদাভাবে শেখানো হয়েছে। এই বই সেগুলোকে একটা project-এ জোড়ে। Python-এর মৌলিক ধারণা লাগবে — variable, function, class, loop।
