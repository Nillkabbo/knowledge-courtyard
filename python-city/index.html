📜 প্রস্তাবনা — নগরীর দরজায়

তুমি পাইথন নগরীর ফটকে দাঁড়িয়ে আছো। ভেতরে ২০টি গিল্ড — প্রতিটি গিল্ডে একজন মাস্টার, একটা আসল সমস্যা, এবং Python-এর একটা শক্তি। তুমি শিক্ষানবিশ হিসেবে ঢুকবে, মাস্টার বিল্ডার হিসেবে বেরোবে।

You stand at the gates of Python City. Inside: 20 guilds — each with a master, a real problem, and one power of Python. You enter as apprentice, leave as Master Builder.

এই বই আলাদা কেন? কারণ এটা Python শেখায় না। এটা সমস্যা সমাধান শেখায় — Python দিয়ে। প্রতিটা গিল্ডে একটা আসল সমস্যা আছে। তুমি ভাববে, হাত গুটোবে, ভুল করবে, তারপর Python-এর শক্তি দিয়ে সমাধান করবে। Syntax মুখস্থ নয় — প্যাটার্ন বুঝবে।

Why this book is different: It doesn't teach Python. It teaches problem-solving with Python. Each guild has a real problem. You think, struggle, fail, then solve it using Python's power. Not syntax memorization — pattern understanding.

🐍 নগরীর মানচিত্র: ৪টি ধাপ, ২০টি গিল্ড। ধাপ ১ (গিল্ড ১-৫): ভিত্তি — variables, control flow, functions, data structures, strings। ধাপ ২ (গিল্ড ৬-১০): নির্মাণ — file I/O, error handling, modules, OOP, comprehensions। ধাপ ৩ (গিল্ড ১১-১৫): দক্ষতা — decorators, context managers, generators, functional, concurrency। ধাপ ৪ (গিল্ড ১৬-২০): বাস্তব জগৎ — data analysis, web scraping, APIs, automation, synthesis।

4 phases, 20 guilds. Phase 1 (1-5): Foundation. Phase 2 (6-10): Building. Phase 3 (11-15): Mastery. Phase 4 (16-20): Real World — data analysis, scraping, APIs, automation, and how to build ANYTHING.

🤖 AI যুগে কেন প্রোগ্রামিং? AI কোড লিখতে পারে। কিন্তু AI ভাবতে পারে না কী বানাতে হবে, কেন বানাতে হবে, কীভাবে সমস্যা ভাঙবে। প্রোগ্রামিং শেখো না কোড লেখার জন্য — শেখো চিন্তা করার জন্য। AI তোমার হাতিয়ার, তুমি কারিগর।
