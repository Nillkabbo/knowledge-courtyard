বারো লাইনের ইঞ্জিন

The Twelve-Line Engine · The Claude Code Journey
প্রথম prompt থেকে নিজের agent পর্যন্ত — আটাশটি দরজা, চার পর্বে। প্রথমে Claude Code প্রতিদিন নিরাপদে, দক্ষভাবে চালাতে শিখবে; তারপর ঢাকনা খুলে দেখবে টার্মিনালে তোমার একটা keystroke কীভাবে token হয়, model-এর কাছে যায়, tool চেয়ে ফেরত আসে; তারপর বিশেষজ্ঞের বিচারবুদ্ধি। শেষ দরজায় দেখবে, পুরো জিনিসটা আসলে বারো লাইনের একটা loop — আর নিজেই সেটা বানাবে।

From your first prompt to your own agent — twenty-eight doors in four parts. Part 1 (Use it): first session, the core loop, CLAUDE.md, permissions, commands and skills, MCP, headless and CI, team rollout. Part 2 (Under the hood): model vs harness, tokens, next-token generation, training, the context window, the stateless API, prompt caching, tool use. Part 3 (Control and other roads): harness-enforced safety, subagents, provider adapters, other backends. Part 4 (Trust, proof, judgement): prompt injection, evals, any-tool transfer, the Agent SDK, extended thinking, prompt craft, model and pattern choice. Door 28 reveals the twelve-line loop and you build your own agent. Book 59 (The Terminal Craftsman) is the deep feature reference alongside.
কপি-পেস্টের এক ঘণ্টা — The Copy-Paste Hour

ঢাকার এক গুমোট দুপুর। তোমার সামনে ticket: কোনো customer-এর billing address না থাকলে Invoices API 500 দেয়। তুমি stack trace কপি করো, chat-এ পেস্ট করো, একটা fix পাও, editor-এ পেস্ট করো, test চালাও। দুটো অন্য test ভাঙে। আবার কপি, আবার পেস্ট। এক ঘণ্টা পর আঙুলে ব্যথা, মাথায় ধোঁয়া। তারপর কেউ terminal-এ শুধু claude লেখে, আর একই কাজ আট মিনিটে শেষ হয় — file খোলা, test চালানো, ভুল পড়া, আবার চেষ্টা — তুমি শুধু দেখো।

A humid Dhaka afternoon. The ticket: the Invoices API returns 500 when a customer has no billing address. You copy a stack trace into a chat, get a fix, paste it into the editor, run the tests; two others break. Copy, paste, repeat. An hour later someone types claude in a terminal and the same job finishes in eight minutes while you only watch.

সেই মুহূর্তে জিনিসটাকে জাদু মনে হয়। এই বই তোমাকে দুই ধাপে নিয়ে যাবে। প্রথমে জাদুটা ঠিকভাবে চালাতে — আটজন ওস্তাদ: এক আমিন, এক নৌকার কারিগর, এক ট্রেনচালক, এক ওটি-নার্স, এক ময়রা, এক বিদ্যুৎ-মিস্ত্রি, এক দই-কারিগর, এক হেডমাস্টার। তারপর জাদু ভেঙে দিতে — আরও উনিশজন: মুনশি, কম্পোজিটর, তাঁতি, সেতারি, পেশকার, ওয়ার্ড-বয়… যেদিন দেখবে ভেতরে কী ঘোরে, সেদিন তুমি নিজেই বানাতে পারবে, অন্য যেকোনো model-এর সঙ্গে, অন্য যেকোনো tool-এ। শেষ ছাদে মীরা দেখাবেন, আটাশজনের সবাই আসলে একটাই যন্ত্রের একেকটা লাইন শেখাচ্ছিলেন।

In that moment it feels like magic. This book takes you in two steps. First, to drive the magic well — eight masters: a surveyor, a boatbuilder, a train driver, a theatre nurse, a sweet-maker, an electrician, a doi-maker, a headmaster. Then to break the magic — nineteen more: a munshi, a compositor, a weaver, a sitar master, a court clerk, a ward-boy… The day you see what turns inside, you can build it yourself, for any model, in any tool. On the last rooftop Mira shows that all of them were teaching lines of one machine.
