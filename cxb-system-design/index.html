সিস্টেমের নীলনকশা

এক সার্ভারের কোড থেকে কোটি ব্যবহারকারীর সিস্টেম — ছয়টি পাঠে স্কেল, নির্ভরযোগ্যতা আর বাস্তব-জগতের নকশার পুরো মানচিত্র। Cloud X Berry-এর ব্যাখ্যা ও ভিজ্যুয়ালে।

প্রস্তর-লিপি · Prologue

কেন এই বই?

লোকাল মেশিনে কোড চলে, কিন্তু রিয়েল ইউজার এলে সব ভাঙে — কেন? কারণ সিস্টেম ডিজাইন মানে ফাংশন লেখা নয়: বাড়ন্ত ট্রাফিক, বিপর্যয়, দামি সার্ভার আর বদলানো রিকোয়ারমেন্টের সাথে বাঁচার নকশা। একবার যে এই চোখ তৈরি করে, সে আর কোড আগের মতো দেখে না।

এই বইটি Cloud X Berry চ্যানেলের System Design প্লেলিস্টের ৬টি ভিডিওর বিশ্বস্ত রূপান্তর — শিক্ষক যেভাবে ব্যাখ্যা করেছেন, যে ভিজ্যুয়াল ব্যবহার করেছেন, ঠিক সেভাবেই।

৬টি দরজা পেরোলে তুমি পাবে: ডিজাইনের আট নীতি, স্কেলের বিল্ডিং ব্লক (LB/cache/NoSQL/microservices), works-on-my-machine-এর আসল কারণ, WhatsApp কীভাবে কোটি মেসেজ পাঠায়, Reverse Proxy vs LB vs API Gateway, আর observability-র ভাষা OpenTelemetry।
