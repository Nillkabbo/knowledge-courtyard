The Linux Terminal Path
Unix-এর জন্মকথা থেকে আজকের টার্মিনাল-অস্ত্রাগার — ছয়টি পাঠে অপারেটিং সিস্টেমের পুরো মানচিত্র। Cloud X Berry-এর ব্যাখ্যা ও ভিজ্যুয়ালে।

📜 প্রস্তর-লিপি · Prologue

Linux খুব কঠিন মনে হয় যারা C-ড্রাইভে বড় হয়েছে — কিন্তু একবার গোড়ার ধারণাগুলো (এক রুট, সবকিছু-ফাইল, ছোট টুলের জোড়া) বুঝলে পুরো জগৎ সহজ হয়ে যায়। সার্ভার, ক্লাউড, ডেভ-মেশিন — আধুনিক তথ্য-প্রযুক্তির পেছনের বেশিরভাগ জগৎ চলে এই কার্নেলের উপরে।

এই বইটি Cloud X Berry চ্যানেলের Linux & Operating Systems প্লেলিস্টের ৬টি ভিডিওর বিশ্বস্ত রূপান্তর — শিক্ষক যেভাবে ব্যাখ্যা করেছেন, যে ভিজ্যুয়াল ব্যবহার করেছেন, ঠিক সেভাবেই। আর তার সাথে পথের ছয় মাস্টার — মুচি হারুন মিয়া, ক্রেতা-নির্দেশিকা জাহেনা বেগম, গ্রন্থাগারিক রফিক চাচা, দারোগা কর্নেল সালাহউদ্দিন, দোভাষী মাহমুদা আপা — যাঁদের জীবনই প্রতিটা পাঠ বলে দেয়।

৬টি দরজা পেরোলে তুমি পাবে: Unix-এর জন্ম ও দর্শন, চার OS-জগতের ভূগোল, লিনাক্স ফাইল-সিস্টেমের গাছ, ১০টি কোর কনসেপ্ট, Windows বনাম Linux কমান্ড-ম্যাপ, আর দৈনন্দিন কাজ বদলে দেওয়া ১০টি আধুনিক টুল। শেষ দরজায় ছয় নম্বর চেয়ারটা তোমার অপেক্ষায়।
