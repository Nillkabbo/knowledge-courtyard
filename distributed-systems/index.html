সংযোগের সেতু

The Bridge of Connections
একটা মেশিনে যা ফিট করে না — তা হাজার মেশিনে ছড়িয়ে দাও।
দশটি দরজা — Lamport-এর ঘড়ি, Dijkstra-এর সিগন্যাল, Brewer-এর CAP উপপাদ্য, Paxos ও Raft, MapReduce, Dynamo, এবং বাইজেন্টাইন ফল্ট টলারেন্স।

What doesn't fit on one machine — spread across a thousand. Ten doors: Lamport clocks, Dijkstra semaphores, CAP theorem, Paxos and Raft consensus, MapReduce at Google, Amazon Dynamo, Byzantine fault tolerance, Satoshi's blockchain, and modern data-intensive architecture.
একটা মেশিনের শেষ — The End of One Machine

একজন কারিগর একটা মেশিনে সব কাজ করতেন। প্রথমে ভালো চলত — কিছু কাজ সামলে নিত মেশিন। কিন্তু ক্রমশ কাজ বাড়ল। হাজার, লক্ষ, কোটি ব্যবহারকারী। একটা মেশিনের সীমা এল। CPU গরম, মেমরি ভর্তি, ডিস্ক ফুল। মেশিন থামল। সব কাজ থামল। একটা মেশিনের উপর নির্ভরশীলতা একটা দুর্বলতা — সে থামলে সব থামে।

A craftsman did all work on one machine. At first it worked — some tasks, manageable. But work grew. Thousands, millions, billions of users. The machine hit its limit. CPU hot, memory full, disk full. The machine stopped. All work stopped. Dependency on one machine is a weakness — if it stops, everything stops.

এই বই তোমাকে শেখাবে — কীভাবে একটা সিস্টেমকে হাজার মেশিনে ছড়িয়ে দেবে। যেন একটা মেশিন থেমে গেলেও সিস্টেম চলে। যেন কোটি ব্যবহারকারী এলেও সিস্টেম স্কেল করে। যেন ডেটা নষ্ট না হয়। Lamport (১৯৭৮) থেকে Kleppmann (২০১৭) — ৩৯ বছরের বিতরণ সিস্টেমের জ্ঞান দশটি দরজায়।

This book teaches you — how to spread a system across a thousand machines. So one machine failing doesn't stop the system. So millions of users still scale. So data isn't lost. From Lamport (1978) to Kleppmann (2017) — 39 years of distributed systems knowledge in ten doors.
