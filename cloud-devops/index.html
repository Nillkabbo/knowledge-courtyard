মেঘের ভেতরে — Inside the Cloud

তুমি প্রতিদিন docker compose up চালাও। kubectl apply করো। git push করো। কিন্তু এর পেছনে কী ঘটছে? একটা container আসলে কী — lightweight VM? না। সেটা শুধু একটা Linux process, namespaces দিয়ে ঘেরা, cgroups দিয়ে সীমাবদ্ধ। Kubernetes কী করে? সে শুধু বারবার চেক করে — desired state আর actual state মিলছে কি না। এটাই reconciliation loop।

You run docker compose up every day. kubectl apply. git push. But what happens behind the scenes? What is a container, really — a lightweight VM? No. It's just a Linux process, wrapped in namespaces, limited by cgroups. What does Kubernetes do? It simply checks, over and over — does desired state match actual state? This is the reconciliation loop.

এই বই তোমাকে নিয়ে যাবে মেঘের ভেতরে। Docker (2013) দেখিয়েছিল container = isolated process। Google (2014) Kubernetes উন্মুক্ত করেছিল — Borg-এর উত্তরাধিকারী। HashiCorp (2014) Terraform দিয়েছিল — infrastructure as code। Google SRE (2016) error budget এর ধারণা ছড়িয়েছিল। Cilium (2018) eBPF দিয়ে kernel-level networking শুরু করেছিল। এই দশটি দরজায় তুমি দেখবে — কীভাবে আধুনিক cloud infrastructure কাজ করে।

This book takes you inside the cloud. Docker (2013) showed container = isolated process. Google (2014) open-sourced Kubernetes — heir to Borg. HashiCorp (2014) gave us Terraform — infrastructure as code. Google SRE (2016) spread the error budget concept. Cilium (2018) began kernel-level networking with eBPF. Through ten doors, you will see how modern cloud infrastructure works.
