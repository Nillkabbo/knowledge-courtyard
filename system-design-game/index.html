The City Builder's Codex
একটা সার্ভার থেকে একটা নগরী — System Design-এর বিশটি স্থান।
প্রতিটা স্থানে একজন নগর কারিগর। প্রতেকজন System Design-এর এক একটা রহস্য শেখাবেন।

From one server to a city — twenty places, twenty masters of System Design. A complete mastery reference.
নগর নির্মাতার যাত্রা — The Builder's Journey

তুমি একটা অ্যাপ বানাতে পারো। একটা সার্ভার, একটা ডেটাবেস, কিছু API। কাজ হয়। কিন্তু যখন ইউজার বাড়ে — ১০ থেকে ১০,০০০, ১০,০০০ থেকে ১০ লাখ — সব ভেঙে পড়ে। সার্ভার থামে, ডেটাবেস হাঁপায়, ইউজার অপেক্ষা করে, তারপর চলে যায়।

You can build an app. One server, one database, some APIs. It works. But when users grow — 10 to 10,000, 10,000 to a million — everything breaks. Server stops, database gasps, users wait, then leave.

একটা শহরও এভাবে শুরু হয় — একটা বাড়ি, একটা কুয়ো, একটা পথ। কিন্তু যখন মানুষ আসে — হাজার, লাখ, কোটি — তখন দরকার: ফটক যেখানে ভিড় সামলাবে, গোলাঘর যেখানে শস্য সংরক্ষিত থাকবে, সংরক্ষণাগার যেখানে নথি সাজানো, দূত যারা একে অপরের সাথে কথা বলবে না বৈঠক ছাড়া। এটাই System Design — একটা গ্রামকে নগরীতে রূপান্তর করা।

A city starts the same way — one house, one well, one road. But when people come — thousands, millions — you need: gates to manage crowds, granaries to store provisions, archives for organized records, couriers who communicate without all meeting. This IS system design — transforming a village into a city.

একদিন তুমি শুনলে — প্রাচীন নগর নির্মাতাদের একটা দস্তাবেজ আছে। বিশটি স্থান। প্রতিটা স্থানে একজন মাস্টার: ভিত্তি রক্ষক, ফটক রক্ষক, গোলাঘর সংরক্ষক, মহল্লা স্থপতি, সরাইখানা প্রধান, সংকেত প্রহরী, শুল্ক আদায়ক, বাজার বিতরণকারী, সংরক্ষণাগারিক, কাতেব, আয়না গিল্ড, চৌরাস্তার মানচিত্রকার, হিসাব রক্ষক, প্রবীণ পরিষদ, মোহরদার, রিং মানচিত্রকার, ঝড় প্রহরী, মানচিত্রকার, আর দুইজন মহা-কমিশনার। প্রতেকজন এক একটা System Design-এর রহস্য জানেন।

One day you heard — the ancient city builders left a codex. Twenty places. Each with a master: foundation mason, gate keeper, granary keeper, quarter architect, caravanserai master, signal watcher, customs collector, market distributor, archivist, scribe, mirror guild, crossroads cartographer, ledger keeper, council of elders, seal registrar, ring cartographer, storm watcher, mapmaker, and two grand commissioners. Each knows one secret of system design.
