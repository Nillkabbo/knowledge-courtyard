The Codebuilder's Guild
একটি ফিচারের যাত্রা — আইডিয়া থেকে প্রোডাকশন পর্যন্ত।
দশটি দরজা: SDLC ও মেথডলজি (Waterfall→Agile→DevOps→Platform Engineering), SOLID ও Clean Code, Design Patterns (GoF 1994), Testing (TDD/BDD), Git ও কোলাবোরেশন, Architecture Patterns (Clean/Hexagonal/Microservices/Serverless), DevOps ও CI/CD, Software Security, AI-Assisted Development ও ভবিষ্যৎ, এবং একটি ফিচারের সম্পূর্ণ যাত্রা।

A feature's journey — from idea to production. Ten doors: SDLC methodologies (Waterfall→Agile→DevOps→Platform Engineering), SOLID principles and clean code, design patterns (GoF 1994), testing (TDD/BDD), Git and collaboration, architecture patterns (Clean/Hexagonal/Microservices/Serverless), DevOps and CI/CD, software security, AI-assisted development and the future, and one feature's complete journey from idea to production.
একটি ভাস্করের গল্প — The Sculptor's Story

একজন ভাস্কর পাথর কাটেন। প্রথমে অগোছালো — বড় ছুরি, ভাঙা টুকরো। তারপর সূক্ষ্ম — ছোট হাতুড়ি, নিখুঁত রেখা। শেষে চর্চন — বালির কাগজ, মসৃণ পৃষ্ঠ। প্রতিটি ধাপে একটি নিয়ম, একটি সরঞ্জাম, একটি কৌশল। কোডও তেমন — প্রথমে কাঁচামাল (আইডিয়া), তারপর গঠন (আর্কিটেকচার), তারপর সূক্ষ্মতা (টেস্টিং), তারপর মসৃণতা (CI/CD)। একজন কারিগর শুধু কোড লেখে না — সে একটি জীবন্ত ব্যবস্থা গড়ে তোলে যা বছরের পর বছর টিকে থাকে।

A sculptor cuts stone. First rough — big chisel, broken pieces. Then fine — small hammer, precise lines. Finally polishing — sandpaper, smooth surface. Each step has a rule, a tool, a technique. Code is the same — first raw material (idea), then structure (architecture), then precision (testing), then smoothness (CI/CD). A craftsman doesn't just write code — they build a living system that lasts for years.

এই বই তোমাকে নিয়ে যাবে সফটওয়্যার ইঞ্জিনিয়ারিংয়ের সম্পূর্ণ ল্যান্ডস্কেপে — ১৯৭০-এর Waterfall থেকে আজকের AI-assisted development পর্যন্ত। প্রতিটি দরজায় একজন কারিগর — Beck (TDD), Fowler (refactoring), Martin (clean code), Gamma (patterns) — যারা এই শিল্প তৈরি করেছেন। তুমি শিখবে কীভাবে একটি ফিচার আইডিয়া থেকে শুরু করে requirement, design, code, test, deploy, monitor হয়ে ব্যবহারকারীর হাতে পৌঁছায়। এটি শুধু কোড নয় — এটি একটি পেশার গল্প।

This book takes you through the complete landscape of software engineering — from 1970s Waterfall to today's AI-assisted development. Each door features a craftsman — Beck (TDD), Fowler (refactoring), Martin (clean code), Gamma (patterns) — who built this craft. You'll learn how a feature goes from idea through requirements, design, code, test, deploy, monitor to the user's hands. This isn't just code — it's the story of a profession.
