Each shop has a craftsman. Each teaches a data structure. Hear the story, write code, run it — all in your browser.
কারিগরের যাত্রা — The Craftsman's Journey

তুমি জানো Python। তুমি জানো frontend, backend। কিন্তু একটা সিনিয়র ইঞ্জিনিয়ার আর একটা মিড-লেভেল ইঞ্জিনিয়ারের পার্থক্য কী?

You know Python. You know frontend, backend. But what separates a senior engineer from a mid-level one?

পার্থক্য হলো — চিন্তার গভীরতা। একটা সমস্যা দেখে সিনিয়র ইঞ্জিনিয়ার ভাবেন: "এর সময়ের জটিলতা কত? কোন ডেটা স্ট্রাকচার সবচেয়ে উপযুক্ত? এটা কি O(n) করা যায়, O(n²) নয়?"

The difference is — depth of thought. Seeing a problem, a senior engineer thinks: "What's the time complexity? Which data structure fits best? Can this be O(n), not O(n²)?"

একদিন তুমি শুনলে — শহরের পুরনো অংশে একটা বাজার আছে। আঠারোটা দোকান। প্রতিটা দোকানে একজন মাস্টার কারিগর — জ্যোতির্বিদ (যিনি মাপেন), আরবেস্ক খোদাইকারী, টালি নির্মাতা, মুক্তোর মালা কারিগর, কাফেলা প্রধান, তালা নির্মাতা, মসলা ব্যবসায়ী, বংশবিদ, তাঁতি, গোত্রপতি, গ্রন্থাগারিক, পাথর বিভাজক, ক্যালিগ্রাফার, রেশম ব্যবসায়ী, মালি, অলিগলির পথিক, নকল-নির্দেশকারী, পরচুলা-নকশা তাঁতি। প্রতেকজন এক একটা Data Structure বা Algorithm শেখান — কিন্তু শুধু তত্ত্ব নয়। তাঁরা শেখান কীভাবে সেটা AI ইঞ্জিনিয়ারিং-এ ব্যবহার হয়। আর তুমি শুধু পড়বে না — তুমি কোড লেখবে, চালাবে, দেখবে।

One day you heard — in the old quarter of the city, there's a bazaar. Eighteen shops. Each with a master craftsman — the astrolabe maker (who measures), the arabesque carver, the tile maker, the pearl-necklace maker, the caravan master, the locksmith, the spice merchant, the genealogist, the weaver, the clan elder, the librarian, the stone splitter, the calligrapher, the silk merchant, the gardener, the alley explorer, the concord maker, the pattern-card weaver. Each teaches a data structure or algorithm — but not just theory. They teach how it's used in AI engineering. And you won't just read — you'll write code, run it, see it work.
