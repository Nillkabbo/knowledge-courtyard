উপাত্তের ভল্ট

The Data Vault
একটি query-র যাত্রা — সারি থেকে অর্থ পর্যন্ত।
তেরটি দরজা: relational model (Codd 1970), SQL, indexing (B-tree, Hash), ACID transactions, normalization, NoSQL, distributed databases, query optimization, data warehousing, একটি query-র সম্পূর্ণ যাত্রা, এবং নতুন — ভেক্টর ডাটাবেস, ANN indexing (HNSW/IVF), ও AI উপাত্ত স্থাপত্য।

A query's journey — from rows to meaning. Ten doors: the relational model (Codd 1970), SQL, indexing (B-tree, Hash), ACID transactions, normalization, NoSQL (key-value, document, graph), distributed databases (replication, sharding, CAP), query optimization, data warehousing + OLAP, and one query's complete journey through the database engine.
একটি ফাইল ক্যাবিনেটের গল্প — The Filing Cabinet

তুমি একটি অফিসে কাজ করছো। হাজার হাজার কাগজ — চালান, চুক্তি, রিপোর্ট। সব এলোমেলো স্তূপে। একটি নির্দিষ্ট চালান খুঁজতে কতক্ষণ লাগবে? ঘণ্টা। কিন্তু যদি প্রতিটি কাগজ একটি নিয়মে সাজানো থাকে — তারিখ অনুসারে, ক্লায়েন্ট অনুসারে, সংখ্যা অনুসারে? তাহলে সেকেন্ডে পাওয়া যায়। এটাই ডাটাবেস — একটি সুসংগঠিত ফাইল ক্যাবিনেট যা হাজার হাজার সারিকে সেকেন্ডে খুঁজে বের করতে পারে।

You work in an office. Thousands of papers — invoices, contracts, reports. All in messy piles. How long to find a specific invoice? Hours. But if each paper is organized by a rule — by date, by client, by number? Then found in seconds. This is a database — an organized filing cabinet that can search thousands of rows in seconds.

এই বই তোমাকে নিয়ে যাবে উপাত্তের জগতে — Codd-এর relational model (১৯৭০) থেকে আধুনিক distributed database পর্যন্ত। প্রতিটি দরজায় একজন কারিগর — Codd, Stonebraker, Vogels — যারা এই স্থাপত্য তৈরি করেছেন। তুমি শিখবে কীভাবে একটি query ডাটাবেসে প্রবেশ করে, indexing-এর মাধ্যমে দ্রুত খুঁজে বের হয়, transaction-এর মাধ্যমে নিরাপদে সম্পন্ন হয়, এবং distributed system-এ প্রতিলিপি তৈরি করে।

This book takes you into the world of data — from Codd's relational model (1970) to modern distributed databases. Each door features a craftsman — Codd, Stonebraker, Vogels — who built this architecture. You'll learn how a query enters the database, is found quickly through indexing, completes safely through transactions, and is replicated across distributed systems.
